# Free My TV Plus

**Главный экран для Samsung Tizen с поиском VoKino, личными подборками и возвратом из приложений.**

Публичный форк [Free My TV](https://github.com/simbasjungles/free-my-tv). Основные доработки предназначены для Samsung Tizen 6+ и проверялись на телевизоре AU7170.

## Возможности

- **Поиск VoKino с главного экрана.** Результаты обновляются во время набора названия, без нажатия Enter. Учтены особенности первого ввода экранной клавиатурой Samsung.
- **История и избранное.** При подключении собственного аккаунта VoKino доступны личные разделы и продолжение просмотра. Публичный каталог и поиск работают без токена и ключа TMDB.
- **Открытие карточки фильма.** Выбранный фильм открывается непосредственно в VoKino. Воспроизведение и доступность определяет сам сервис.
- **От 1 до 16 карточек.** Начальное значение - 16; количество можно уменьшить в настройках. Облегченная отрисовка и уменьшенные изображения делают переключение карточек плавнее.
- **Возврат на главный экран.** После закрытия любого приложения из панели избранного, запущенного из Free My TV, фоновый сервис возвращает главный экран и восстанавливает выбор. Добавление в избранное включает возврат, удаление отключает его. Переход в другое приложение отменяет возврат.
- **Автозапуск после включения ТВ.** Сервис учитывает выход из ожидания и приостановку таймеров Samsung. Работа зависит от прошивки и разрешений сертификата.
- **Необязательное оформление TizenTube.** Отдельная утилита меняет иконку и задает начальные настройки блокировки рекламы, SponsorBlock и DeArrow. Последующие изменения настроек пользователем сохраняются.

## Избранные приложения

Удерживайте OK на приложении в панели избранного, чтобы открыть редактор сразу на нем. Короткое нажатие OK по-прежнему запускает приложение.

- ↑ ↓ - выбрать приложение;
- ← → - переместить добавленное приложение;
- OK - добавить в избранное или убрать из него;
- Back - закрыть редактор.

Порядок сохраняется сразу и остается после перезапуска. Редактор также доступен через настройки, пункт «Избранные приложения».

## Сборка для Samsung

Нужен Python 3. Выполните из корня репозитория:

```sh
python3 tizen/build.py --plus --generic --preview
```

Результат:

- `FreeMyTV-Plus-tizen.wgt` - неподписанный пакет приложения;
- `out/tizen-plus/` - файлы для предпросмотра в браузере.

Параметр `--generic` исключает личные настройки из сборки. Без него используется локальный `config.properties`.

Для подписи профилем Tizen Studio:

```sh
python3 tizen/build.py --plus --generic --sign YOUR_PARTNER_PROFILE
```

Замените `YOUR_PARTNER_PROFILE` именем собственного профиля. Для фонового сервиса нужен партнерский сертификат Samsung с разрешением для вашего телевизора. Сертификаты, пароли, токены и подписанные пакеты в репозитории не публикуются.

Идентификатор приложения сохранен: `FreeMyTVio.FreeMyTV`. Для обновления существующей установки требуется прежняя авторская подпись. Plus устанавливается как обновление того же приложения, а не как отдельная параллельная копия.

В настройках Smart Hub включите автозапуск последнего приложения и закрепите Free My TV.

## Настройка и ограничения

[Подробная инструкция](tizen/plus/README.md) описывает подключение личных разделов VoKino, работу сервиса возврата, оформление TizenTube и запуск проверок.

- Дополнения Plus имеют русский интерфейс и предназначены для Tizen 6+.
- VoKino, TizenTube и Emby устанавливаются отдельно.
- Возврат из Emby проверялся без работающего сервера; воспроизведение с сервером отдельно не проверялось.
- На других моделях Samsung автозапуск и возврат требуют проверки владельцем.
- Обычные сборки Android, webOS и Tizen сохранены. Дополнения Plus включаются только параметром `--plus`.

## Проверки

Автоматические проверки GitHub собирают исходные приложения Android, webOS и Tizen, проверяют переводы и совместимость общего интерфейса, а также собирают Plus и запускают тесты его дополнений.

Браузерные тесты проверяют поиск во время набора, первый ввод экранной клавиатурой, изменения поля без события ввода, размер окна при открытой клавиатуре, страницы результатов, возврат назад и восстановление выбора. Они используют вымышленные фильмы и подмененный API без личных аккаунтов.

Команды для локального запуска приведены в [инструкции Plus](tizen/plus/README.md#проверки).
