# Free My TV Plus для Samsung

Это дополнительная сборка из исходников Free My TV, а не готовый подписанный пакет для любого телевизора. Дополнения находятся в этой папке; `overlay.py` применяет проверяемые изменения к общему интерфейсу только при `--plus`. Если исходный проект изменит места интеграции, сборка остановится с ошибкой совместимости.

## Сборка

Нужен Python 3. Из корня репозитория:

```sh
python3 tizen/build.py --plus --generic --preview
```

Создаются неподписанный `FreeMyTV-Plus-tizen.wgt` и браузерный предпросмотр `out/tizen-plus/`. Параметр `--generic` исключает личные настройки из сборки. Без него используется локальный `config.properties`, как в исходном проекте.

Для подписи своим профилем Tizen Studio:

```sh
python3 tizen/build.py --plus --generic --sign YOUR_PARTNER_PROFILE
```

Сервис требует Samsung Partner certificate с разрешением для вашего телевизора. Обычной подписи может быть недостаточно. Сертификаты, пароли, DUID и подписанные пакеты не хранятся в этом репозитории.

Идентификатор приложения сохранен: `FreeMyTVio.FreeMyTV`. Обновление существующей установки требует прежней авторской подписи. Не удаляйте установленное приложение ради смены подписи: это может потерять его данные. Название Plus помогает отличить сборку, но отдельным параллельным приложением она не является.

## VoKino

Публичный каталог и поиск используют HTTPS API VoKino без личного токена. Установленное приложение VoKino должно иметь ID `UMHvZ0dWqo.AnalogWatch`. OK на карточке открывает карточку фильма в VoKino; воспроизведение и доступность определяет сам сервис.

Личные разделы требуют собственного аккаунта. Доступные вкладки и их порядок можно настроить в пункте «Каталоги и вкладки» или в отдельном меню «Разделы VoKino».

Для личных разделов адаптер читает запись `fmtv.vokino.account` из приватного `localStorage` приложения на телевизоре. Автоматического переноса чужого аккаунта или публичного сервера токенов нет. Владельцы, умеющие работать с локальным Tizen Web Inspector, могут самостоятельно создать запись в контексте Free My TV:

```js
localStorage.setItem('fmtv.vokino.account', JSON.stringify({
  base: 'https://api.vokino.pro/v2',
  token: 'YOUR_OWN_TOKEN',
  key: 'my-account'
}));
```

Заменяйте заглушку только локально на своем телевизоре, затем перезапустите приложение. `key` служит локальным идентификатором кеша: при смене аккаунта задайте другое значение. Поддержаны только HTTPS API доменов VoKino `.pro`, `.co`, `.org`, `.tv`. Не добавляйте токен в исходники, сборку, URL запуска фильма или GitHub issues. Это запись в хранилище приложения, а не системный менеджер секретов.

Для отключения аккаунта удалите `fmtv.vokino.account`, `fmtv.vokino.feed.v5` и старый `fmtv.vokino.feed.v4` в том же приватном контексте и перезапустите приложение. Для обычного скрытия вкладок удалять аккаунт не нужно.

## Каталоги и вкладки

В настройках откройте **Каталоги и вкладки**. На главной у каждого включенного сервиса свой ряд. Порядок по умолчанию - Кинопоиск, VoKino, Иви. При первом открытии Иви включается, если приложение добавлено в избранное. Для Кинопоиска также нужен API-ключ из настроек поиска.

- ↑ ↓ выбирают сервис, ← → выбирают действие.
- **Показывать** включает или скрывает ряд.
- **Порядок** включает перемещение. Используйте ↑ ↓, затем OK или Back.
- **Вкладки** открывает настройки ряда. В этом меню можно скрывать и переставлять вкладки теми же действиями.

У Кинопоиска доступны «Популярное», «Фильмы», «Сериалы», «Топ-250», «Семейное», «Мультфильмы» и «Скоро». У Иви - «Фильмы», «Сериалы» и «Мультфильмы». Это публичные каталоги. Личные история и избранное доступны у VoKino при подключенном аккаунте. Каждый «Обзор» чередует карточки из всех включенных вкладок своего сервиса без повторов. Саму вкладку «Обзор» можно переместить или скрыть.

Общая настройка количества карточек задает от 1 до 16 карточек на странице каждой вкладки. Постеры загружаются по мере появления рядов и карточек на экране. Порядок и видимость сохраняются на телевизоре в `fmtv.catalogs.v1`. Публичные страницы Кинопоиска и Иви кешируются в `fmtv.catalog.feeds.v1`.

## Навигация и верхние кнопки

Стрелки ↑ ↓ перемещают фокус между верхними кнопками, вкладками и карточками каждого сервиса и панелью избранных приложений. Экран прокручивается до выбранного ряда. Если карточек нет, этот уровень пропускается. Стрелки ← → переключают вкладки и карточки внутри текущего ряда, OK открывает карточку в приложении сервиса. Запоминается последняя выбранная верхняя кнопка; при первом открытии это настройки.

В настройках есть переключатели **Кнопка «Телеканалы»** и **Кнопка «Входы HDMI»**. Они скрывают соответствующие значки верхнего ряда и сохраняют выбор после перезапуска. Рядом расположены выключатели поиска VoKino, Кинопоиска и Иви; последние два появляются при добавлении соответствующего приложения в избранное. Выключение поиска VoKino скрывает только кнопку поиска, вкладки каталога сохраняются. Видимые кнопки сдвигаются вправо без пустых мест, скрытые пропускаются при навигации. Настройки всегда доступны. Переключатели относятся к значкам в Free My TV, а не к системным функциям телевизора.

## Общий поиск

Откройте кнопку с лупой и плюсом в верхнем ряду. Free My TV одновременно ищет во всех выбранных сервисах и показывает карточки по мере получения ответов. Карточки разных сервисов чередуются, а под названием указано, где откроется фильм. Если один сервис не отвечает, результаты остальных доступны сразу.

В **Настройках** переключатели **Общий поиск · VoKino**, **Общий поиск · Кинопоиск** и **Общий поиск · Иви** задают, куда отправлять запрос. По умолчанию выбраны все три. Нужные приложения должны быть в избранном, для Кинопоиска также нужен API-ключ. Отдельные кнопки поиска управляются независимо. Переключатель **Кнопка «Общий поиск»** скрывает общую лупу. Выбор сохраняется на телевизоре.

## Поиск Кинопоиска

Добавьте установленный Кинопоиск в избранные приложения. В верхнем ряду появится отдельная кнопка с буквой «К» и лупой, а в настройках - **Кнопка «Поиск Кинопоиска»** и **Ключ поиска Кинопоиска**. Переключатель скрывает кнопку, оставляя само приложение в избранном. Удаление Кинопоиска из избранного убирает кнопку и оба пункта настроек. Выбор видимости сохраняется при перезапуске и повторном добавлении приложения. Поддержан установленный Tizen ID, заканчивающийся на `.kpTizen`.

Каталог предоставляет отдельный сервис [Kinopoisk API Unofficial](https://kinopoiskapiunofficial.tech), а не аккаунт онлайн-кинотеатра. Зарегистрируйтесь у этого сервиса, получите собственный API-ключ и введите его на телевизоре при первом открытии поиска либо через настройки. Лимиты определяет ваш тариф API. Ключ хранится в приватном `localStorage` приложения на телевизоре (`fmtv.kinopoisk.key.v1`) и отправляется только в заголовке HTTPS-запросов к `kinopoiskapiunofficial.tech`. Он не включается в сборку, ссылки запуска, кеш результатов или сервис возврата. Для замены и удаления используйте тот же экран настройки ключа.

Результаты с постерами отображаются внутри Free My TV, обновляются при наборе от двух символов после паузы 400 мс и сохраняют исправления Samsung IME. На странице до 20 результатов, при открытой клавиатуре видны две строки, без клавиатуры - пять. ← → переключают страницы, OK открывает выбранную карточку. Поиск VoKino и поиск Кинопоиска независимы.

Для перехода в ТВ-приложение дополнительно запрашивается `kinopoiskHDId` выбранного фильма. Наличие фильма в каталоге не гарантирует наличие такой ссылки или доступность просмотра по подписке. При отсутствии ТВ-ссылки показывается сообщение; главная приложения вместо карточки не запускается. После выхода из Кинопоиска действует возврат из избранного, сохраняются запрос, страница и выделение поиска. Кеш результатов находится в `fmtv.kinopoisk.search.v1`, смена или удаление ключа очищает его.

Видимые результаты дополнительно проверяются по публичному `ViewOption` со страницы самого Кинопоиска. Если сервис сообщает `UNWATCHABLE`, `UNPURCHASABLE` и отсутствие кнопки, появляется отметка **Нет просмотра**. Карточку с описанием по-прежнему можно открыть. Наличие внутреннего ID само по себе не считается доступностью просмотра. Сбой сети, неполный ответ и отсутствие подтвержденных данных дают **Не проверено**, а не отметку недоступности. Проверка анонимная: отражает каталог для текущего региона, не состав вашей подписки и ограничения профиля.

Проверяются только видимые строки, не более двух одновременно. Ввод и показ результатов не ждут завершения проверок. Уточнение ID расходует один запрос вашего каталожного API на новый видимый фильм; запрос доступности идет непосредственно Кинопоиску без API-ключа и учетных данных. Публичные результаты кешируются на шесть часов, до 128 записей в `fmtv.kinopoisk.availability.v1`; смена или удаление ключа очищает кеш. Публичный интерфейс Кинопоиска может измениться: в этом случае доступность останется непроверенной.

## Поиск Иви

Добавьте установленное Иви в избранные приложения. Появятся отдельная кнопка «И» с лупой и соседний выключатель **Кнопка «Поиск Иви»** в настройках. Выключатель скрывает только кнопку; удаление Иви из избранного также убирает этот пункт настроек. Поддержан Tizen ID, заканчивающийся на `.ivi`.

Поиск использует публичный каталог сайта Иви без отдельного ключа и без переноса аккаунта. Результаты находятся внутри Free My TV, обновляются при наборе и имеют до 20 карточек на странице. Поддерживаются фильмы и сериалы; при выборе передается команда открытия карточки соответствующего типа. Доступность просмотра и оплату определяет само приложение Иви. После выхода действует возврат из избранного с восстановлением запроса, страницы и выделения. Кеш поиска `fmtv.ivi.search.v1` хранит только данные результатов на телевизоре.

## Разделы VoKino и состав Обзора

В настройках откройте «Разделы VoKino», рядом с количеством карточек. Доступны история, избранное, продолжение просмотра, популярное, новинки, обновления, высокий рейтинг, фильмы, сериалы, мультфильмы, мультсериалы, документальные фильмы и сериалы, аниме и ТВ-шоу. Наличие карточек зависит от ответа VoKino; некоторые категории могут быть пустыми.

- ↑ ↓ выбирают раздел, ← → выбирают действие в строке.
- «Показывать» и OK включают или скрывают вкладку.
- «Порядок» и OK включают перемещение: ↑ ↓ меняют место раздела, OK или Back завершают перемещение. Все изменения сохраняются сразу.
- Back вне режима перемещения возвращает в настройки.

По умолчанию «Обзор» идет первым и автоматически наполняется из всех включенных разделов. Отдельно выбирать источники Обзора не нужно. Остальные вкладки следуют выбранному порядку; карточки Обзора чередуются между ними в этом же порядке, повторы убираются. В истории сначала идут недосмотренные фильмы, затем остальные записи. «Продолжить просмотр» использует только недосмотренные записи из последних загруженных карточек истории. Скрытие вкладки исключает ее из Обзора. Если выключить все разделы, Обзор остается пустым.

При первом запуске с аккаунтом сохраняется привычный набор: история и избранное, оба участвуют в Обзоре. Без аккаунта начальным источником служит популярное. Остальные разделы изначально выключены. Настройки хранятся только на телевизоре в `fmtv.vokino.sections.v1`.

Загружаются только включенные источники, не более двух одновременно. История и продолжение просмотра используют общую загрузку истории. В кеше хранится до 16 карточек на источник; все вкладки сохраняют настраиваемое количество карточек и постраничное переключение. Изменение порядка не требует повторной загрузки уже включенных источников. Прежний отдельный выбор источников Обзора больше не учитывается; включенные вкладки и их порядок сохраняются при обновлении. Поиск и кнопки главного экрана работают при любом числе вкладок, длинный список вкладок прокручивается при перемещении стрелками.

## Избранные приложения

Возврат включается автоматически для приложений, добавленных в панель избранного. Удаление из панели отключает возврат и отменяет уже включенное ожидание закрытия. Выбор относится к приложениям, а не к вкладке избранных фильмов VoKino. Поиск и карточки фильма также учитывают, добавлен ли VoKino в избранные приложения.

На главном экране удерживайте OK на нужном приложении около секунды. Откроется редактор с выделенным приложением. Короткое нажатие OK запускает приложение без открытия редактора. В редакторе ↑ ↓ выбирают строку, ← → меняют позицию, OK добавляет или убирает приложение. Порядок сохраняется сразу. Редактор доступен и через настройки, пункт «Избранные приложения».

## Оформление дока

В настройках откройте «Оформление дока». Доступны цвет рамки выбранного приложения, цвет фона дока и прозрачность его фона от 0 до 100% с шагом 5%. Прозрачность 0% означает непрозрачный фон, 100% - полностью невидимый. Иконки при этом сохраняют свою яркость.

↑ ↓ выбирают настройку, ← → меняют значение. Цвета выбираются из палитры из 12 вариантов. Изменения сразу видны на настоящем доке в нижней части экрана и автоматически сохраняются на телевизоре. Back возвращает в настройки. «Сбросить оформление» возвращает белую рамку, графитовый фон и прозрачность 40%.

Рамка рисуется внутри значка, поэтому не меняет расстояние между приложениями. Увеличение выбранного значка до 140% сохраняется.

## Автозапуск и возврат

`autostart.js` - отдельный сервис `FreeMyTVio.Autostart`. Он опрашивает состояние питания через loopback API телевизора и учитывает приостановку таймеров в Instant On. Он запускает главный экран после пробуждения с ограниченным числом повторов при явной ошибке.

Перед запуском приложения из текущего избранного интерфейс передает сервису список установленных избранных приложений и включает наблюдение только за выбранным приложением. Список не зашит в код. Для неизвестных заранее приложений используется их установленный Tizen ID; отдельные особенности TizenTube и Emby сохранены. После подтвержденного закрытия сервис возвращает Free My TV. Выбор другого приложения пользователем отменяет возврат. Для TizenTube учитывается отдельное нативное окно YouTube. Фоновые сервисы TizenTube/Emby не считаются открытым окном проигрывателя.

Внутренний HTTP сервер слушает только `127.0.0.1:8099`: `/status` для диагностики и ограниченные POST-команды наблюдения. Команда `/favorites?ids=...` синхронизирует список установленных приложений, `/watch/app?appId=...` принимает только ID из этого списка. Неверные ID, служебные приложения и сам главный экран отклоняются. После перезапуска сервиса интерфейс повторно передает список перед запуском приложения. Токены аккаунта этому сервису не передаются. Поддержка зависит от прошивки Samsung; это не перехват системной кнопки Home. Проверено на AU7170, воспроизведение Emby с работающим сервером отдельно не проверялось.

В настройках Smart Hub включите автозапуск последнего приложения и закрепите Free My TV. Главный интерфейс сохраняет штатное `background-support="disable"`; возврат обеспечивает сервис.

## Необязательное оформление TizenTube

Основная сборка не устанавливает и не модифицирует TizenTube. Для своего пакета [TizenTube Cobalt](https://github.com/reisxd/TizenTube), проверенного с версией 2.1.1:

```sh
python3 tizen/plus/tizentube.py TizenTubeCobalt.wgt TizenTube-Plus-unsigned.wgt
```

Утилита заменяет иконки собственными SVG/PNG из `tizentube-icons/` и добавляет `tizentube-preferences.js` перед загрузкой userscript в обоих прокси. Старая подпись удаляется, результат нужно подписать своим подходящим сертификатом. Входной пакет сохраняется. При несовместимых исходниках утилита останавливается.

Настройки применяются один раз: реклама, SponsorBlock sponsor/interaction/selfpromo, ручной пропуск intro/outro/filler, DeArrow. Последующие изменения пользователя сохраняются. Для обновления кешированной иконки Samsung может потребоваться полная перезагрузка телевизора.


Для браузерных тестов можно задать `CHROME_PATH` к установленному Chrome вместо загрузки Chromium. Тесты используют синтетические фильмы и подмененный API, без аккаунтов и запросов к VoKino. Проверяются первый IME-ввод, изменения поля без событий input, масштаб при клавиатуре 1920x568, страницы, Back, восстановление выбора и отсутствие двойной обработки кнопок. Дополнительно проверяются удержание и короткое нажатие OK, перестановка, добавление и удаление приложений, синхронизация возврата и сохранение порядка после перезапуска.

Общие исходники `web/` сохраняют требования ES5 исходного проекта. Дополнение Plus использует fetch, URL и AbortController и предназначено для Tizen 6+, не для старых Tizen/webOS. Новые подписи и телевизоры требуют отдельной проверки владельцем.
